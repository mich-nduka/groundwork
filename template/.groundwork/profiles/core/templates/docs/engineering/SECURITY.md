# Security Requirements

## Objectives and scope
What we're protecting, from whom, and where the trust boundaries sit (the points where data crosses between levels of trust).

## Identity and access
How people sign in, what each role may do, least privilege, and how privileged operations are handled.

## Data protection
How data is classified, encrypted, retained and deleted, and how secrets are handled. For an installed app, also the device permissions it asks for (camera, location, contacts and so on), why, and what still works when the person says no.

## Input and interface security
Input validation, rate limiting, abuse prevention and interface protections — where relevant.

## Dependencies and supply chain
How dependencies are reviewed, kept updated and watched for vulnerabilities.

## Logging and incident response
What never goes into logs, what needs an audit trail, and how incidents are escalated.

## Verification
Links to the security tests, reviews, threat models and requirements that verify all of the above.
