# Search and Sharing (SEO)

> Web profile. How people find the site through search engines and shared links. SEO means search engine optimisation. The pages themselves are listed in `docs/web/CONTENT.md`.

## Goals
The searches and audiences that matter most, and which pages should answer them.

## URL structure
The patterns for page addresses, and the rules for changing them (case, trailing slashes, language prefixes).

## Redirects
Every moved or removed page gets a redirect, so links and search rankings survive.

## Page metadata
For each page type: the title pattern, where the description comes from, the canonical URL (the one official address of a page), and whether search engines may index it.

|---|---|---|---|
| | | | |

## Structured data
Machine-readable descriptions of page content that search engines use for richer results. Add them only where they earn their place, and name the types used.

## Sharing previews
The image, title and text shown when a page is shared in social or messaging apps.

## Crawling
The sitemap, the robots rules, and the pages kept out of search (drafts, thank-you pages, internal search results).

## Measurement
How search traffic and conversions are measured, and how visitor consent for analytics and tracking is collected and respected.
